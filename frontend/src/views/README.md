# 页面视图目录

本目录存放系统的主要业务页面视图，对应前端路由所映射的各功能模块。

## 页面清单

- **Login.vue**
  登录页，集成物理引擎驱动的机器人交互动画，提升登录场景的沉浸感与品牌识别度。

- **Dashboard.vue**
  能源态势总览页，包含 4 个 KPI 卡片与 4 个 ECharts 图表，用于关键指标与趋势的可视化呈现。

- **EnergyAnalysis.vue**
  能耗分析页，提供多维度的能耗数据查询、对比与趋势分析能力。

- **DeviceMonitor.vue**
  设备监控页，实时展示设备运行状态、告警信息与运维指标。

- **SpatialTwin.vue**
  空间孪生主视图，集成混沌工程控制台、3D Canvas 渲染、容灾终端日志展示，以及 API 主备节点 failover 演示。

- **AiAgent.vue**
  AI 智慧决策页，包含终端日志流、能力雷达图、流式 SSE 聊天对话、图片与文档上传，以及动态 ECharts 渲染。

- **AdminDashboard.vue**
  管理后台仪表盘，面向管理员提供系统配置、用户与权限管理等功能入口。

- **HelloWorld.vue**
  默认示例组件，项目初始化时保留，可作开发参考。
