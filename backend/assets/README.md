# assets — 论文与报告图表资源目录

存放项目论文及报告所需的可视化图表 PNG 文件。

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `data_distribution_comparison.png` | 数据分布对比可视化图表 |
| `feature_dimension_shrink.png` | 特征维度缩减可视化图表 |
| `pca_dimension_reduction.png` | PCA 降维可视化图表 |

这些图表由 `generate_thesis_charts.py` 与 `generate_report_charts.py` 脚本生成，供论文、报告及文档引用。
